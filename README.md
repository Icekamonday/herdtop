# herdtop

herdtop is a full-screen terminal browser of the coding-agent sessions on one machine: it tells which session to touch, what touching it costs, and why. It is a rewrite of cctop, an earlier browser for Claude Code sessions alone, with one reader per agent kind, Claude Code and Codex first. It runs in any terminal, with or without [Herdr](https://github.com/herdrdev/herdr); inside Herdr, it also shows the tab of each session and opens a session in a tab of its own.

There is no code yet. [docs/functional-description.md](docs/functional-description.md) describes cctop, which is the behaviour that herdtop starts from.
